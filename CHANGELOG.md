# Changelog

## 0.1.0 — 2026-10-06

First public release / 首个公开版本。

- Editable BAT + PowerShell workflow for original audio or ALAC output.
- Source sample-rate/channel preservation, ffprobe checks and full output decode.
- Anonymous-first extraction with explicitly configured authentication fallback.
- Unicode-safe filenames, collision handling and source retention on failure.
- Official yt-dlp update fallback, SHA256/version verification and check caching.
- First-launch upstream dependency setup with pinned checksums; no third-party EXEs in published assets.
- English and Simplified Chinese READMEs, FAQ/cookie instructions and dependency/license notices.
- Synthetic local regression checks and documented live-site scope.

Known scope: Windows x64, PowerShell 5.1; YouTube/Bilibili examples validated, other yt-dlp sites not individually verified. External access restrictions remain outside the project's control.
